# 2025-10
环境感知型语音智能窗帘驱控终端
本项目基于嵌入式技术设计环境感知 + 语音交互一体化智能窗帘控制系统，集成多类环境传感器、语音识别模块与步进电机执行机构，搭配自主设计的硬件扩展板实现硬件整合与电路转接。系统可实时采集光照、温湿度、雨水等环境数据，结合语音指令双重控制窗帘开合，摆脱传统手动操作，实现窗帘智能化、自动化管控，适用于家居、室内场景使用。

物料：ASR-PRO 语音识别控制模块,光敏传感器,温湿度传感器,雨水传感器,步进电机模块（28BYJ-48),嘉立创设计硬件电路打板（降成本）
